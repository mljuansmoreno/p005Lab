# Materiales de revisión, borrador de desarrollo

**Nombre propuesto:** Ruta Estadística, sujeto a disponibilidad y asociación del propietario.

**Descripción breve:** Recorre tus datos y comprende resultados estadísticos con cálculos locales en R.

**Descripción:** Importa tablas, confirma tipos y faltantes, elige una ruta y conserva cifras, gráficos y evidencia reproducible. Incluye descriptivos, frecuencias de respuesta única, comparación de dos grupos, asociación y relación lineal simple. No exige cuenta ni modelo de lenguaje. La inferencia requiere justificar diseño y supuestos; el programa no establece representatividad o causalidad.

**Formatos/límites:** CSV/TSV UTF-8 y XLSX restringido; 50 MiB, 100.000 registros sin cabecera, 200 columnas. Exporta HTML offline, CSV, PNG, R y proyecto portátil. No ofrece PDF ni macros.

**Requisitos:** Windows x64; las versiones concretas aceptadas y memoria deben actualizarse con pruebas reales antes de publicar. Docker se instala por separado y MCP es optativo. No se deben anunciar sus funciones sin completar aceptación.

**Privacidad:** Los datos permanecen en archivos locales sin cifrado propio; no hay telemetría de la aplicación ni cuentas. El usuario elige exportar o conectar un cliente MCP; ese cliente puede transmitir contenido a un proveedor externo. La política definitiva debe alojarse en una URL real y describir comportamiento de instalación/desinstalación verificado.

**Soporte/editor:** PENDIENTE datos reales del propietario. No utilice dominios ficticios para una publicación.

**Revisor:** Abrir Inicio, Probar ejemplo, Calcular. Confirmar seis mediciones y media 15,5. Revisar Interpretación, exportar HTML y abrir sin conexión. Reiniciar y abrir proyecto. Repetir con R global ausente en cuenta estándar. No se necesitan credenciales ni internet para el ejemplo.

Las capturas deben corresponder a la aplicación ejecutada, no a maquetas. Falta completar pruebas, identidad, licencias y certificación según [lista de publicación](../../documentacion/lista_publicacion_tienda.md).
