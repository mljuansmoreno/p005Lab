# ADR: Paridad de motores

Fecha: 27/10/2026. Estado: decisión de implementación, sujeta a aceptación completa.

La API Docker y el trabajador Windows cargan rutaanalitica 0.1.0. El contenedor no abre SQLite. Sin ejecución Docker no se declara paridad.
